# Nodpack releases

Downloads for **Nodpack**, the mobile sales app for Twenty CRM. Works with Quo.

*Talk, call or text. Your Twenty keeps up.*

This repository holds installers only. There is no source code here. Each build is a [release](../../releases) named `v<version>-<build number>`.

## Download

Open the [latest release](../../releases/latest) and pick the file for your system.

| System | File | Install |
|---|---|---|
| Linux (Ubuntu 22.04 or newer, Debian) | `Nodpack-<version>.deb` | `sudo apt install ./Nodpack-<version>.deb` |
| Windows 10 or 11 | `Nodpack-<version>.exe` | Run the installer. SmartScreen may warn: choose **More info**, then **Run anyway**. |
| macOS | `Nodpack-<version>.dmg` | Drag Nodpack to Applications. The first time, right-click it and choose **Open**. |

The Windows and macOS builds are not code-signed yet, which is why the system warns you on first launch.

Phones: the Android and iOS builds go out through the Google Play and TestFlight testing tracks, not this page.

## What you need

- A Twenty workspace (Cloud or self-hosted). You sign in with your own Twenty account.
- Optionally a Quo workspace, to log calls and texts into Twenty.

## Report a problem

Open an [issue](../../issues) with the release version, your operating system and what happened. Please leave out phone numbers, emails, names of real contacts and message text.
